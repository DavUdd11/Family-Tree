# Family Tree (Coursework Project)

A simple Python console program I built in my first-year university coursework to model a family tree and query relationships (parents, children, siblings, cousins, etc.) using object-oriented programming.

Project file: 

FamilyTree

What it does

Stores family members as Person objects (name, birth date, optional death date)

Builds relationships between people (parents/children, siblings, cousins, etc.)

Provides a menu-driven interface to:

Display parents / children / grandchildren

Display immediate & extended family

Display siblings & cousins

Show birthdays (list + sorted “birthday calendar”)

Show simple statistics:

Average age at death

Children per person

Average children per person

How to run

Make sure you have Python 3 installed.

Run the program:

python FamilyTree.py


Use the on-screen menu and enter names exactly as stored in the program.

Notes

Family data is currently hard-coded inside the script (Uddin & Torres members).

Some relationships (like grandchildren) are stored separately for convenience and aren’t automatically inferred.
